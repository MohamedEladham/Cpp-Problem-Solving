## 🚀 Levels Breakdown

### 🟢 Level 1 – Fundamentals & Core Logic

Focuses on basic programming concepts and foundational problem-solving across **50 practical challenges**:

* **Input / Output & Basic Calculations:**
 Handling user input, arithmetic operations, calculating areas of various geometric shapes, and variable swapping.

* **Conditions & Validation:**
 `if` / `switch` statements, grade evaluations, loan calculations, range validations, and input validation loops.

* **Loops & Control Flow:**
 `for` / `while` loops, printing sequences, summation of odd and even numbers, factorials, powers, prime number checking, and interactive PIN code login systems with security attempt limits.

### 🟡 Level 2 – Advanced Math, Patterns & Single Arrays

Introduces advanced number manipulation and single-dimension array operations across 

**48 structured exercises**:

* **Advanced Number Algorithms:** 
Perfect numbers, digit manipulation such as reversing numbers, digit summation, frequency counting, and palindrome checks.

* **Patterns & Text Generation:**
 Number and letter pyramid patterns, generating 3-letter combinations, password guessing simulations, and simple text encryption and decryption.

* **Randomization & Utilities:**
 Generating random numbers, characters, and license keys, alongside custom implementations of mathematical functions such as `Abs`, `Round`, and `Floor`.

* **Single Arrays (`Arrays`):** 
Comprehensive operations including filling arrays with random numbers, finding maximum/minimum elements, calculating sums and averages, copying specific elements such as prime, odd, and distinct numbers, shifting and shuffling elements, and frequency/existence checks.

### 🟠 Level 3 – Matrices, Strings, Vectors & File Handling

Strengthens intermediate-to-advanced data structures and file operations across 

**51 comprehensive problems**:

* **Two-Dimensional Arrays (`Matrices`):** 
Random matrix generation, row and column sum calculations, matrix transposing, element-by-element multiplication, scalar and sparse matrix validations, and finding palindromes or common elements in matrices.

* **Recursion & Sequences:** 
Solving algorithmic problems using recursive functions, including calculating Fibonacci sequences.

* **Advanced String Manipulation:** 
Capitalizing and lowering words and letters, counting vowels and character frequencies, splitting and joining strings and vectors, trimming whitespaces, reversing words, replacing text, and removing punctuation.

* **File Handling & CRUD Operations:**
 Parsing client records, adding and loading clients from text files, and implementing core file-based CRUD operations such as searching, deleting, and updating client records by account number.

### 🔴 Level 4 – Advanced Algorithms & Date/Time Library Systems

Focuses on complex system logic, custom time libraries, and advanced data structuring across 

**29 specialized challenges**:

* **Number-to-Text Conversion:**
 Translating numerical values into written text.

* **Leap Year & Time Unit Calculations:** 
Checking leap years and calculating time units across years, months, and days.

* **Calendar Systems:** 
Getting day names from dates and generating complete monthly and yearly calendars.

* **Date Manipulation & Arithmetic:**
 Converting total days to dates, adding/subtracting days and custom time units to/from dates, checking date sequences such as before, after, and equal, determining the last day/month, and calculating differences between dates in both directions.

* **Periods & Vacations:** 
Calculating actual vacation days, return dates, checking period overlaps, calculating period lengths in days, checking whether a date falls within a period, and calculating overlap days between periods.

* **Structs & Formatting:** 
Validating dates, converting dates between strings and structured formats (`struct`), and formatting dates using custom format strings.
